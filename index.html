Python / GIS

Flood Risk GIS Toolkit

以 Python 建立可重現的洪氾風險「示範性篩選」流程。讀取合成網格資料，進行 Min–Max 正規化、危害與脆弱度指標計算，依示範門檻分級，輸出 CSV 及 GeoJSON，供 GIS 工作流程練習與檢視。

Python 3GIS / GeoJSONCSVCLIunittestGitHub Actions
GitHub Repository ↗CI / Tests ↗
Reproducible workflow
合成 CSV→Python 計算
風險分級→CSV + GeoJSON
單元測試→GitHub CI

程式碼、測試及範例資料請參閱專案儲存庫。

此專案使用合成資料與未校準的示範指標；不是正式淹水潛勢圖、水理模擬、實際地點風險預測或工程決策工具。
